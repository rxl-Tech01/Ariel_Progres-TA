    Tahap pengembangan

    Dashboard masih dalam tahap demo. Semua angka dan status adalah data dummy atau data uji. A7670E merupakan target integrasi; pembacaan kuota modem belum terhubung ke aplikasi ini.

    Koneksi dan cek kuota

    {% if demo_mode %}Online pada riwayat hanya status simulasi. Nantinya, {% endif %}status terhubung dihitung dari heartbeat dalam 180 detik terakhir. Status koneksi tidak membuktikan kuota masih tersedia.

    Perhatikan usia data

    Cek gagal mempertahankan nilai dan waktu sukses terakhir. Waktu cek adalah waktu laporan diterima server. Umur pembacaan dihitung saat layar diperbarui.

    Arti indikator kuota

    Aman: lebih dari 2 GB. Peringatan: 1–2 GB. Kritis: kurang dari 1 GB. Nol berarti kuota habis; “Belum diketahui” berarti nilainya belum tersedia.

    Refresh dan perintah modem

    Refresh hanya mengambil data yang sudah tersimpan di server. Tidak ada AT Command atau USSD yang dikirim dari tombol ini. Dashboard belum menyediakan perintah cek kuota manual.

    {% if simulation %}

    Tentang simulasi

    Data sintetis memakai database sementara terpisah, dihapus saat simulator ditutup normal. Simulasi tidak mengirim heartbeat otomatis dan bukan data penelitian.
